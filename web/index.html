    Honest limits

    • In this demo, a demo runner on this laptop plays your device, so the master key is checked here. In the real app it is checked on your device and never sent to the server.
    • Someone can still film the screen during the one allowed session.
    • A friend can act inside the live session until you end it.
    • First use wins: if a copier uses the link first, your friend is refused.
    • Sites without a connector get an assisted mode, not a one-time login.
    • The server can see site names and usernames, never passwords.
